# Java DSA Practice

Beginner data structures and algorithms problems solved in Java, written while preparing for software developer roles.

## Problems

| File | What it does |
|------|--------------|
| Sum.java | Finds the sum of all elements in an array |
| Swap.java | Swaps two values using a temporary variable |
| SwapEnds.java | Swaps the first and last elements of an array |
| Reverse.java | Reverses an array using two pointers |
| Palin.java | Checks whether a string is a palindrome |
| Vowels.java | Counts the vowels in a word |
| SecondLargest.java | Finds the second largest number in an array |

## How to run

1. Install Java (JDK 17 or later).
2. Open a terminal in this folder.
3. Run any file with: `java FileName.java`
